How to Activate a License

  1. Generate the license key above.
  2. Download and privately save the CSV file containing the plaintext key. Store it securely — never commit it to the repository.
  3. Download the updated licenses.json file.
  4. Replace licenses.json in your GitHub repository with the downloaded file.
  5. Commit and push the change to the default branch.
  6. Wait for GitHub Pages to publish the update (typically under 1 minute).
  7. Send only the plaintext license key to the customer. Never share the CSV or the hash.
Important: Generating a key does not activate it. The key only becomes valid after its hash is published in licenses.json on GitHub Pages and the EJEC app downloads the updated file.

Why only hashes? GitHub Pages is a public, read-only static host. There is no server-side secret to sign keys, and no way to prevent anyone from reading the repository. Publishing only SHA-256 hashes means an observer who reads licenses.json cannot reconstruct any valid product key.
